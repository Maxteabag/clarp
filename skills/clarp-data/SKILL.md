# Data
Publish with `clarp-agent-artifacts create "$CLAUDE_PWA_SESSION" data TITLE SUMMARY JSON_PAYLOAD`.
Create type `data` with equal-width `columns` and `rows` arrays. Optionally add `chart` with `kind`, `category_column`, and `value_column`.
