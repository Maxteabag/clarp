# Differences between the Python Host and the Rust Host that are meant to be there.
# One per line: the difference's id from the report, then why. The register with the reasoning
# is server-rs/docs/differences.md; an id is added here only once it is written there.

# A plain send that has to wait is announced with `queue-updated` (the Python Host announces
# nothing: reference defect R5). One event more, which the differ shows as these four.
66b251f369fb  send-while-busy: queue-updated for the message that joined (queue_depth)
a6a1fa158ccb  send-while-busy: the same event (queue_revision)
f588400bad1e  send-while-busy: the same event (queue_started)
d64ffe6fffea  send-while-busy: the event the Python Host does send, now second

# The reply that closes a completed turn is `final` (the Python Host says null when the turn
# before had settled: reference defect R6).
dfcb5143ebc3  two-turns: the second reply
15b27f8ead44  log-pages: the second reply, in the newest page
9c9b8bbc7447  log-pages: the second reply, in the page a client with nothing gets
00f5d90896a6  log-pages: the second reply, to a client that catches up
cdeb37c253ec  turn-timer: the second reply, which answered a message that had waited

# A notification's preview of what was said aloud does not show an emotion tag the engine
# acts out (the Python Host shows "[sigh]" there: reference defect R10).
0d1fdd0f0ff9  voice-markup: the preview of the notification

# A turn is counted from its own start (the Python Host counts a turn that follows one that
# was stopped from the start of the stopped one: reference defect R11; issue 354).
a46e99cc9bde  turn-timer-after-stop: turn_started_at while the next turn runs

# After a turn that had waited in the queue, the last completed message is the agent's answer
# (the Python Host still shows the user's message there: reference defect R12).
d4b9221921eb  turn-timer: last_completed_message at rest, after the second turn

# What the Host sends an agent by itself (an answer that is delivered, a goal that is taken
# up again) does not move the user's focus to that agent (the Python Host moves it: reference
# defect R14).
18ab05fa986e  approval: the agent's row says it is the open one after its answer was delivered
661f8028e8eb  approval: the snapshot's focus, the same

# The answer to a discard says the artifact is not pinned (the Python Host says pinned true
# beside pinned_at null: reference defect R15).
23ad255cb543  library: pinned in the answer to the discard of a pinned artifact
