# Defects of the reference

What the conformance runs showed to be wrong, or unsteady, in the Python Host. The Rust Host does
not copy these. Each is reported to whoever owns the Python Host's releases; none is fixed from
here.

Reported: on 15 Nov 2026, by the owner's word, all fifteen that were open went to the release
owner (the agent Arnold) in one message, grouped by cause. R11 had been fixed before (PR 357).
A defect that is fixed there loses its registered difference here, and the recordings are made
again.

Taken and triaged the same day: the triage and its order are issue 360 of `Maxteabag/clarp`.
First what can hurt a user (R14, R4, R7), then what the Host does with the transcript after a
turn as one investigation (R1, R9, R3, R12, R13, R16), then the small exact ones (R10, R15, R5,
R6, R8, R2). The release owner says so here each time one is fixed and installed. R14 was fixed
the same evening (PR 361, `b30029b4`) and is in force on both of the owner's Hosts since 15 Nov
23:03 (the release owner's word of 16 Nov: at 23:21 a message from another Host started a turn in
an agent and the focus stayed where it was).

In force on both of the owner's Hosts since 16 Nov 2026, 23:27 (elitebook) and 23:28
(laptopstudio), which run main `21263308` (the release owner's word of that hour, who tried two of
them on the installed release itself): R20; R22, with what followed it (PRs 385 and 389: `~someone/`
and a user name with a NUL in it are answered, quietly); R23 for a name the transcript spells as
the agent has it, with the first point of R27; R24, also for a janitor's and a goal's cron; R25,
with the rule that a request whose header names are no HTTP tokens is refused (PR 384). Not fixed,
on issue 360: R18, R19, the letters of R23 that are spelled another way
("Rachél" for Rachel), and the earlier ones as triaged there. R26 is issue 372.

The release owner's word of 17 Nov 2026, evening: R29 to R37, the case of a message that is given to a
tool as text, and the restart under a running turn (R51) are recorded on issue 360 with the counts measured
here; none of R29 to R37 is fixed or installed. His author is on R28 (PR 398: the count is held to be
right, the writing of the state is being made safe against races), then on what the goal keeper reads.
