# Plain INITIAL native seed predicates — source preparation proposal

`seed_membership.py` consumes the existing complete typed raw capture, without
SQL, product import, file access, copied parser execution or rewriting values.
It applies ONLY to exact A4f33/initial_seed and frozen S/L. This is not a general
post-ready/reference oracle, B output approval or a source-ready runner.

The constructor now checks its actual native captured products. Closed-image
qualification checks the independent closed capture against the outer owner's
expected size/pin/mode and compares the returned membership receipt while
retaining the FULL exact raw diff. Outer source/recipe/launch/capture authenticity
is still mandatory; a forged raw object is not proof of a native database.

## Predicates proposed for exact source review

For each of the three selected synthetic owners, turns must cover the declared
N+6 unique traces, local/completed with January request time60*n seconds and
settlement+2seconds. Message membership must be exactly one request and reply
for each of the N populated traces, none for the six pre-seeded future turns.
No extra selected-owner trace/session/message can influence a last-row tie.
Unselected owners and all additional columns/tables stay in the full raw oracle.

Every tenth request retains its independently inserted durable client identity,
negative seq, client:synthetic source, revision1 and updated_at1. Other native
rows use the pinned slot-derived message ID and transcript path/seq. This is
the declared simple fixture's storage contract, not a new product algorithm.
The source supports client matching by unique text; it does not copy record
UUIDs into plain parsed turn IDs. Actual raw ID/path/trace/payload checks are
required rather than assuming the match happened.

Plain record role/text/timestamp, empty tools/cells, user origin, absent kind/
tool/admission, raw sender representation and assistant final/user-null phases
are checked without JSON normalization. Exactly the +2s reply carries the
source-defined completed turn summary, with2000ms worked and zero tool count.
The request carries no summary. Matching exact role/slot/time membership
establishes no timestamp+seq tie inside this selected fixture domain. Imported
row update clocks must be the declared INITIAL import epoch; durable client
values remain1. Revision values stay native, positive, unrenumbered; the helper
does NOT invent or reconstruct the global allocation counter.

These are SOURCE PROPOSALS until exact C review and actual native controls.
Any unanticipated legitimate native row/summary/provenance difference must be
reported and explained; do not alter source data, CP, clocks, indices, raw
fields or treatment to make this contract pass. No all-field/schema/head/CP/
runtime/actor/counter/reference predicate is claimed beyond the listed fields.

## Strong control boundary, not a manufactured positive

`seed_membership_controls.py` takes ONE authentic actual native S INITIAL
capture from the eventually reviewed owner. It first requires that actual
capture to satisfy the predicate. It does not generate passing native rows
using this oracle, copy a native parser or launch any seed/root/test itself.

Fifteen typed single-field negatives change trace owner, backend session, source
path, slot, request summary holder, missing reply summary, phase, origin, native
update clock, client revision and integer storage type, plus native and durable
message IDs, native turn settlement and outcome (C30c2 control amendments).
A sixteenth negative removes an
actual future turn. Each must refuse at the declared contract reason; a wrong
reason/setup failure stops the control driver. Original raw bytes are hashed
before/after. Only the affected table row-vector and one typed row are copied;
no extra snapshot/native work or whole-product deep copy per case is needed.

The authoring gate is the raw storage/causal fixture contract, not internal
helper call shapes. The credible regression is approving a wrong trace/summary/
provenance/clock as an unchanged seed. Existing logical-path and main-file copy
controls cannot observe this risk. No production seam was added. Native-positive
and refusal evidence remains UNEXECUTED; no old control/gate is repeated here.

The driver has no CLI or launch authority. It must be source-qualified and
explicitly included in the same admitted INITIAL S setup under the unchanged
6000s/~17NOK inclusive cap. The current300s controls proposal has not established
this selector's CPU/hash/allocation/reap fit. Do not run it as an extra job or
substitute Actions gates for measurement admission.

## What this does not settle

Even acceptance on an authentic native initial image does not prove later A/B
replay makes zero writes. Raw CP publication, same logical path restore,
actual startup/recovery writers, cache/frontier state, native retry/fallback,
deletion/head/replace/epoch/actor/connection lifetime and later references need
their own source/actual evidence and complete bounds. No2/4-marker/36-allocation
or8192/512 fit follows. A reference reconstructed empty-first has different
work and cannot use this populated-input bound by assertion.

Hashing, per-row validation, tuple/identity sets, temporary encoded raw products
and capture data all have setup/storage/CPU/peak costs still unqualified. This
helper runs outside measured startup/RSS and must not be retained inside a
measured native process to hide observation bias. Physical restore, all-actor
drain, actual roots/readiness/work and whole budget/coverage runner remain OPEN.
