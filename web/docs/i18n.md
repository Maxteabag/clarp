# Localization in the web app

The web app ships in English (the base), Norsk bokmål (`nb`), 简体中文 (`zh-Hans`), हिन्दी (`hi`),
Español (`es`) and Français (`fr`). The shared rules for every Clarp client (languages, fallbacks,
Host-coded strings, what is never translated) are in the i18n conventions; this page is how the web
app does it.

## Where things are

- `web/src/lib/i18n/<lang>.json`: one flat catalog per language, dotted keys
  (`"settings.language.title": "Language"`). `en.json` is the base; a key missing from another
  catalog shows its English.
- `web/src/lib/i18n/comments.json`: a note for the translator per key, where the English alone is
  ambiguous.
- `web/src/stores/i18n.svelte.js`: the current language and `t(key, params)`.
- `web/src/lib/i18n/format.js`: dates, times, relative times, numbers.
- `web/src/lib/i18n/core.js`: the language list, the device-language fallbacks, the endonyms.

## Adding a string

Add the English to `en.json` (and a note to `comments.json` if a translator could misread it), then
use it with `t`. Leave the other catalogs alone; the translation pass fills them.

Plain text:

```json
"chat.empty": "No messages yet"
```
```svelte
<p>{t('chat.empty')}</p>
```

A placeholder, `{name}`; numbers are written the language's way:

```json
"chat.start_with": "Start a chat with {name}"
```
```svelte
{t('chat.start_with', { name: contact.name })}
```

A plural is an object of plural forms chosen by `count`. English needs `one` and `other`; a
translation has the forms its language uses (zh only `other`, others may add `few`/`many`):

```json
"preview.images": { "one": "{count} image", "other": "{count} images" }
```
```svelte
{t('preview.images', { count: n })}
```

An accessibility label is text like any other:

```svelte
<button aria-label={t('chat.refresh')} title={t('chat.refresh')}>…</button>
```

A date or time never goes through a catalog. Use the formatters, which follow the chosen language:

```js
import { formatStamp, formatRelative, formatDateTime } from './i18n/format.js';
formatStamp(turn.ts);         // 14:05 / torsdag / 28. nov.
formatRelative(reset_ms);     // in 2 hours / om 2 timer / 2小时后
formatDateTime(s.mtime * 1000);
```

Also there: `formatDate`, `formatTime`, `formatWeekday`, `formatNumber`, `pluralCategory`. Each
takes the language as its last argument and defaults to the current one.

Outside a component (a store, a plain module), call `t` when the text is shown, not once at import
time, so a language change reaches it.

Do not translate: Clarp, Host, agent and persona names, backend and model names, Tailscale, GitHub,
file names, code, commands, user content.

## The language setting

Settings (the Chats dialog) > Language: System first, then each language in its own name. System
follows the browser's preferred languages (`navigator.languages`), taking the first one shipped:
`nb`/`nn`/`no` give Norsk bokmål, `zh-Hans`/`zh-CN`/`zh-SG`/`zh` give 简体中文, and anything else
English. A choice applies at once, without a reload, and is kept in `localStorage`
(`clarpLanguage`) on this device. The app sets `lang` on `<html>` to the language shown.

## Export and import

```
node web/scripts/i18n-export.mjs /path/to/xfer/web/          # writes en.jsonl
node web/scripts/i18n-import.mjs /path/to/xfer/web/nb.jsonl  # one or more <lang>.jsonl
```

Export writes one line per English key, in catalog order:
`{"key","en","comment","placeholders","plural"}`; for a plural key `en` is the `other` form and
`plural` holds the English forms, otherwise `plural` is `null`.

Import reads lines `{"key","text"}` or `{"key","plural":{"one":…,"other":…}}`, takes the language
from the file name (or `--lang`), and writes `web/src/lib/i18n/<lang>.json` in English catalog
order. Keys the file does not mention keep their translation; keys English no longer has are kept
and reported as stale; a placeholder that differs from the English is reported. Importing the same
file twice writes the same catalog.

The catalogs are bundled by `npm run build` into `static/app/bundle.js`; a non-English catalog is
only parsed when that language is shown.
