# The owner's vision

Recorded from Peter's instructions on 2026-09-05 and 2026-09-06.

The fleet map should let a person understand what their agents are doing by
exploring a living world. It should be intuitive, expressive, fun and visually
appealing. A generic dot labeled “file”, “repo”, “asset” or “host” is not enough:
where possible show which thing, where it belongs, what it does, and how an agent
is interacting with it.

The application develops its visual software procedurally. Agents should have
room to invent mechanisms, nested spaces, expressive animations and interactions
when the evidence exposes an unmet need. They can write real source code and
extend systems; they are not limited to an icon catalog or a tiny drawing language.

The governing balance is **“creative but not disruptive.”** Build on the app's
existing direction. New entities usually become instances of familiar concepts.
A new operation can gain a fitting animation. An integration can gain an interior.
A genuine problem can receive a targeted repair. Replacing the whole metaphor
requires a strong, specific demand; an ordinary novelty batch is not such a demand.

The default World retains The Lantern Works' repository workshops, files,
GitHub harbor and activity machinery. Agent markers are now the agents' existing
Clarp avatars, explicitly replacing the earlier boats. The side-by-side activity
and nested cabinets from the Jacquard experiment remain a separate optional view.

This is a desktop map with pan and zoom, not a diagram that must squeeze every
item onto a phone screen. Off-screen places are normal. Familiar identities and
navigation should remain recognizable as the world expands.

The owner does not want to approve routine plans or compatible improvements.
Proceed with authorized work and make sensible implementation choices. This
autonomy is not permission to turn every new event into a wholesale redesign.
Preserve unrelated work, never perform an unsafe Git checkout, and verify what
actually renders. A successful HTTP response or model call is not visual proof.
