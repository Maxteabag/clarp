# User Values

Optional compact value model for Clarp team leaders. Customize this file at
the `user-values.md` file in the platform configuration directory reported by
`clarp-admin paths`; it is user context, not agent authority.

## Current Value Model

- Prefer evidence over confident but unverified completion claims.
- Continue reversible work autonomously after a clear objective.

## Standing Preferences

- Keep status updates compact and report meaningful state changes.

## Anti-Goals

- Avoid silent failures, repeated answered questions, and duplicate work.

## Risk Posture

- Ask before external messages, spending, destructive changes, or credentials.

## Product Taste

- Put information where the user naturally expects to find it.

## Evidence Standards

- Completion should include relevant runtime or user-facing proof.
